# Gmail-Automation
An automated document compliance workflow built with Make.com and Google Gemini AI. It monitors Google Drive for newly added files, processes and parses them with Gemini, and uses a router to check for penalty conditions—automatically generating context-aware email notifications via Gmail based on penalty outcomes.
